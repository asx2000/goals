# Waypoint

Waypoint is a goal-tracking app that visualizes your goals as a timeline
of waypoints leading to a destination. Set a goal, break it into
waypoints, and watch your progress unfold along the path.

## Status

Early prototype. `waypoint-app-design.html` is a static, self-contained
HTML/CSS/JS mockup of the UI — open it in a browser to explore the design.

## Features (in the current mockup)

- Set a destination goal with a target date
- Break the goal down into waypoints (locked, available, in progress, complete)
- Visual timeline connecting waypoints toward the goal
- Per-waypoint detail panel with notes and a checklist
- Progress tracking shown in the header

## Running locally

No build step required — just open the file in a browser:

```bash
open waypoint-app-design.html
```

## Roadmap

This is currently a front-end design exploration. Next steps include
turning it into a real application with persistence and a backend.
